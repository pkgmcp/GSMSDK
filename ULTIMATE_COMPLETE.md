## 🚀 USAGE

### Quick Start

1. **Open Dashboard**
   ```
   https://your-domain.com/dashboard/index.html
   ```

2. **Connect Device**
   - Click "Connect Device"
   - Select device in browser prompt
   - Grant USB permissions

3. **Select Brand**
   - Choose your device brand
   - Dashboard auto-configures

4. **Perform Operations**
   - Navigate to appropriate tab
   - Use drag-and-drop for files
   - Monitor real-time progress

### Example: Xiaomi Bootloader Unlock

```
1. Open Dashboard → Xiaomi tab
2. Connect Xiaomi device
3. Select "All Model BL Unlock"
4. Confirm unlock in popup
5. Monitor progress bar
6. Wait 72 hours for official unlock
7. Reboot to fastboot
8. Device unlocked!
```

### Example: Qualcomm EDL Flash

```
1. Open Dashboard → Advanced tab
2. Select "EDL Flash XML Multi"
3. Upload scatter XML file
4. Confirm flash operation
5. Monitor EDL progress
6. Device flashes all partitions
7. Automatic reboot when complete
```
